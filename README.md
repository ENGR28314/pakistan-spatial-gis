# 🇵🇰 Pakistan Spatial Master Layers GIS Dashboard

A comprehensive Streamlit GIS application and interactive spatial data simulator covering all 7 core master layers of Pakistan's geographical, hydrological, ecological, and multi-hazard infrastructure.

## 🚀 Live Demo & Deployment
You can deploy this repository directly on [Streamlit Community Cloud](https://streamlit.io/cloud) in under 2 minutes!

## 📂 Features Covered
1. **Administrative Domains:** Boundaries for 4 Provinces, 2 Autonomous Regions, ICT, and the 200 NM Maritime Exclusive Economic Zone (EEZ).
2. **Topography & Ecosystems:** Karakoram, Himalayas, Hindu Kush, Sulaiman, Kirthar ranges, Ziarat Juniper forest, and Indus Mangroves.
3. **Hydrology & IWT Link Canals:** Dynamic flow transfer simulation across Tarbela, Mangla, and all 7 Indus Water Treaty Link Canals.
4. **Lakes, Deserts & Islands:** Manchar, Keenjhar, Attabad, Saif-ul-Muluk, Thar, Thal, Cholistan, Kharan, Astola & Churna Islands.
5. **Multi-Hazard & Seismic Grids:** Active fault line maps (Chaman Fault, MBT), GLOF basins, and flood plains.
6. **GeoJSON Exporter:** Built-in spatial schema exporter compatible with QGIS, ArcGIS, and Web GIS.

## 🛠️ Local Installation & Execution

```bash
# 1. Clone this repository
git clone https://github.com/YOUR_USERNAME/pakistan-spatial-gis.git
cd pakistan-spatial-gis

# 2. Install dependencies
pip install -r requirements.txt

# 3. Launch Streamlit app
streamlit run app.py
```

## 🌐 Deploying to GitHub & Streamlit Cloud
1. Upload `app.py`, `requirements.txt`, and `README.md` to your GitHub repository.
2. Sign in to [Streamlit Community Cloud](https://streamlit.io/cloud).
3. Click **"New App"**, select your repository and `app.py` as the main file path.
4. Click **"Deploy!"**
